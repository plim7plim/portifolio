Bot IA

Projeto desenvolvido durante a extensão de Algoritmos e Lógica de Programação. A aplicação permite que o usuário envie um arquivo PDF e faça perguntas sobre seu conteúdo. As respostas são geradas por um modelo de IA utilizando uma API REST, considerando apenas as informações presentes no documento enviado.

JavaScript API REST e JSON Integração com IA

Jogo Do Número Secreto

O Jogo do Número Secreto é um projeto feito no curso de JavaScript da Alura, onde o sistema gera um número aleatório e o jogador tenta adivinhar qual é. A cada tentativa, o jogo avisa se o número é maior ou menor, até que o acerto aconteça. Ele usa funções, listas, comparações e eventos, além de ter um sistema de narração para acessibilidade de pessoas com deficiência

JavaScript Eventos Console
